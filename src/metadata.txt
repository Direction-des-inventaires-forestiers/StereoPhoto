about= FR: Cette extension permet d'utiliser un dossier de photos aériennes (.TIF) pour les visualiser en stéréoscopie avec le système d'écran approprié. Le dossier doit aussi contenir les fichiers d'orientation (.PAR) associés à chaque photo. L'affichage et l'édition de différentes couches vectorielles sont disponibles dans l'application. Il est aussi possible d'ajouter un modèle numérique de terrain pour permettre aux couches vectorielles d'être positionnées correctement en stéréoscopie. L'application fonctionne sans carte graphique stéréoscopique. 

    EN : This extension allows the use of a folder of aerial photos (.TIF) for stereoscopic visualization using the appropriate display system. The folder must also contain the orientation files (.PAR) associated with each photo. The display and editing of various vector layers are available in the application. It is also possible to add a digital terrain model to allow the vector layers to be positioned correctly in stereoscopy. The application functions without a stereoscopic graphics card.
